## Dataset Overview

The dataset is provided in CSV format and consists of two files:

- train.csv – Contains 160 records used for training machine learning models. It includes all input features along with the target variable **Focus_Score**.
- test.csv – Contains 40 records used for testing and evaluation. It follows the same structure as the training dataset.

## Description

Each row in the dataset represents a single user's daily productivity log.

The dataset includes a mix of numerical and categorical features related to:
- Tasks
- Mood
- Energy levels
- Work hours
- Distractions

## Data Quality

The dataset is:
- Clean and well-structured  
- Ready for analysis and visualization  
- Suitable for machine learning tasks  
- Requires minimal preprocessing  

## Potential Use Cases

- Productivity analysis  
- Focus prediction models  
- Behavioral pattern analysis  
- Machine learning (regression/classification)
