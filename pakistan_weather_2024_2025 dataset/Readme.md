# Pakistan Weather Dataset (2024–2025)

## Description
This dataset contains weather data of Pakistan for the years 2024 and 2025. It can be used for data analysis, visualization, and machine learning projects.

## Features / Columns
- date: Date of observation
- city: City name
- temperature: Temperature (°C)
- humidity: Humidity percentage
- wind_speed: Wind speed
- precipitation: Rainfall / precipitation level
- weather_condition: (Sunny, Rainy, Cloudy, etc.)

## Use Cases
- Exploratory Data Analysis (EDA)
- Weather trend analysis
- Climate pattern study
- Machine learning models (forecasting)
