This is a synthetic dataset created for educational and machine learning practice.

The dataset contains information about students' study habits, sleep patterns, social media usage, exam performance, and stress levels. It is designed to help beginners and intermediate learners practice data analysis, visualization, and machine learning tasks.

Features:
- Study Hours
- Sleep Hours
- Social Media Usage
- Exam Score
- Stress Level

Use Cases:
- Classification (Predict stress level)
- Regression (Predict exam score)
- Data Analysis & Visualization

This dataset is beginner-friendly and can be used for academic projects, portfolios, and practice.
